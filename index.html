                        Sincronizar aparelhos

                        Os dados ficam num gist secreto da sua conta do GitHub. Conecte com o mesmo token em cada aparelho — o painel encontra o gist sozinho e mescla dia a dia (vale a edição mais recente).

                        Criar um token com só a permissão de gist →
                        ver gist

                        O token fica salvo só neste navegador e nunca entra no backup exportado. “Desconectar” apaga o token deste aparelho; o gist continua na sua conta.
